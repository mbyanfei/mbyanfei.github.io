Core principle: use USC accounts for USC-provided services and personal accounts for consumer promotions whenever the program permits it.

1. Activate USC-provided AI first

Highest priority

USC ChatGPT Edu

Use: USC account
  • Sign in using USC NetID.
  • Confirm access to the USC ChatGPT Edu workspace.
  • Use this as the default ChatGPT environment for USC academic work.
  • Do not pay for Plus solely for schoolwork before trying Edu.
Pre-med favorite

USC NotebookLM

Use: USC Google account
  • Create one notebook per course.
  • Add lecture slides, readings, papers, and notes.
  • Generate source-grounded Q&A, study guides, comparisons, and practice questions.
  • Use Audio Overviews when useful.

USC Gemini

Use: USC Google account
  • Check what Gemini features USC has enabled.
  • Use USC-provided Gemini for coursework where appropriate.

USC Microsoft Copilot

Use: USC Microsoft account
  • Check Copilot Chat and Microsoft 365 integrations.
  • Prefer it when work already lives in Word, PowerPoint, Excel, Outlook, or OneDrive.
Strong consumer offer

2. Claim Google AI Pro — 12 months free

Use: Personal Google account
  • Sign in to the personal Google account.
  • Open Google’s college-student AI offer.
  • Verify USC enrollment through the requested verification flow.
  • Add a payment method if required.
  • Confirm checkout clearly shows the 12-month student promotion.
  • Verify the subscription is attached to the personal account.
  • Create an 11-month reminder to review/cancel before paid renewal.
Current redemption deadline: December 31, 2026.

Potential benefits include higher Gemini limits, advanced Gemini capabilities, Google-app integrations, NotebookLM benefits, Deep Research, expanded storage, and additional features as Google updates the plan.

Strong student bundle

3. Claim Microsoft 365 Premium + Copilot — 12 months free

Use: Personal Microsoft account
  • Sign in to the personal Microsoft account.
  • Open Microsoft’s college-student offer.
  • Use USC information for student verification.
  • Add a payment method if required.
  • Confirm the free promotional period before signup.
  • Verify Copilot features are available.
  • Create an 11-month reminder to review/cancel before paid renewal.
Optional

4. Personal ChatGPT Plus

Use: Personal ChatGPT account

USC ChatGPT Edu already covers the main academic use case. A separate personal workspace is useful for personal projects, travel, career planning, non-USC material, and continuity after graduation.

  • Sign in to the personal ChatGPT account.
  • Open OpenAI’s student promotion.
  • Complete student verification.
  • Confirm the promotion applies to the correct account.
  • Create a reminder around 3½ months after activation.
Current offer: 4 free monthly billing periods for eligible U.S. college and graduate students. Claim by: October 31, 2026.

If Plus is currently billed through Apple App Store or Google Play, read the offer terms before changing anything because promotion handling may differ.

Optional

5. GitHub Copilot Student

Use: Personal GitHub account
  • Apply for GitHub Education student verification.
  • Verify USC enrollment.
  • Activate Copilot Student after approval.
  • Confirm the student benefit before paying for anything.

Potentially useful for Python, R, statistics, bioinformatics, computational biology, notebooks, and research automation.

Low priority

6. OpenAI Codex student credits

Use: Personal OpenAI account
  • Complete student verification if coding/data work becomes relevant.
  • Claim the $100 student credit offer only if useful.

This can wait unless programming or computational research is already relevant.

7. Don’t pay for these yet

Claude Pro

  • Use Claude Free when helpful.
  • Do not subscribe unless a specific recurring need emerges.
  • Check whether USC later adds institutionally provided Claude access.

Perplexity Pro

  • Use the free tier when useful.
  • Do not add another research subscription unless the existing stack clearly fails a recurring need.

Best AI stack for a USC pre-med student

1

NotebookLM

Best for learning from assigned material: lecture decks, readings, papers, notes, source-grounded review, practice questions, and exam guides.

2

ChatGPT Edu

Primary tutor and thinking partner for Socratic tutoring, explanations, practice problems, study planning, statistics, and research brainstorming.

3

Gemini / Google AI Pro

Strong complement for Deep Research, Google integrations, multimodal questions, and a second model perspective.

4

Microsoft Copilot

Use mainly when the work already lives in Word, Excel, PowerPoint, Outlook, or OneDrive.

The rule that matters more than every subscription

Check each professor’s AI policy before using AI on coursework.

Usually appropriate

  • Learning concepts
  • Generating extra practice questions
  • Creating private study guides
  • Explaining difficult material
  • Brainstorming questions for an instructor

Requires course-policy review

  • Graded homework
  • Essays
  • Lab reports
  • Submitted code
  • Take-home exams
  • Discussion-board responses

20-minute setup order

  1. USC ChatGPT Edu
  2. USC NotebookLM / Gemini
  3. Google AI Pro student offer
  4. Microsoft 365 Premium student offer
  5. Personal ChatGPT student offer
  6. GitHub Education / Copilot Student
  7. Codex credits if useful
  8. Add every renewal reminder immediately
Recommended core stack: NotebookLM + USC ChatGPT Edu + Google AI Pro + Microsoft Copilot. Add another paid tool only when a recurring use case clearly cannot be handled by this stack.
