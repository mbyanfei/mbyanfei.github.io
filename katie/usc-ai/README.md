## 1. USC-provided AI first

### USC ChatGPT Edu

- [ ] Sign in with USC NetID.
- [ ] Confirm access to the USC ChatGPT Edu workspace.
- [ ] Use it as the default ChatGPT environment for USC academic work.
- [ ] Do not pay for Plus solely for schoolwork before trying Edu.

### USC NotebookLM

- [ ] Use the USC Google account.
- [ ] Create one notebook per course.
- [ ] Add lecture slides, readings, papers, and notes.
- [ ] Generate source-grounded Q&A, study guides, comparisons, practice questions, and Audio Overviews.

### USC Gemini

- [ ] Check which features USC has enabled.
- [ ] Use USC-provided Gemini for coursework when appropriate.

### USC Microsoft Copilot

- [ ] Check Copilot Chat and Microsoft 365 integrations.
- [ ] Prefer it when the work already lives in Word, PowerPoint, Excel, Outlook, or OneDrive.

## 2. Google AI Pro — 12 months free

**Use:** Personal Google account

- [ ] Open Google’s college-student AI offer.
- [ ] Verify USC enrollment.

- [ ] Create an 11-month reminder to review/cancel before paid renewal.

- [ ] Use USC information for student verification.

## 4. Personal ChatGPT Plus — optional

**Use:** Personal ChatGPT account

USC ChatGPT Edu already covers the main academic use case. A separate personal workspace is useful for personal projects, travel, career planning, non-USC material, and continuity after graduation.

- [ ] Complete student verification.
- [ ] Confirm the promotion applies to the correct personal account.
- [ ] Activate only after confirming the free billing periods.
- [ ] Create a reminder around 3½ months after activation.

**Current offer:** 4 free monthly billing periods for eligible U.S. college and graduate students.  
**Claim by:** October 31, 2026.

## 5. GitHub Copilot Student — optional

- [ ] Verify USC enrollment.

- [ ] Confirm the student benefit before paying for anything.

## Best AI stack for a USC pre-med student

1. **NotebookLM** — course-material study engine for lecture decks, papers, notes, source-grounded review, and practice questions.
2. **ChatGPT Edu** — primary tutor and thinking partner for explanations, practice problems, study planning, statistics, and research brainstorming.
3. **Gemini / Google AI Pro** — strong complement for Deep Research, Google integrations, multimodal questions, and a second model perspective.
4. **Microsoft Copilot** — useful when the work already lives in Microsoft 365.
5. **Claude Free** — occasional second opinion; no need to pay unless a specific gap appears.

## The rule that matters most

- [ ] **Check each professor’s AI policy before using AI on coursework.**

Usually appropriate: learning concepts, generating extra practice questions, private study guides, explanations, and brainstorming questions for instructors.

Requires course-policy review: graded homework, essays, lab reports, submitted code, take-home exams, discussion-board responses, and other submitted work.
