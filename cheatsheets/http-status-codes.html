Pairs that matter in real debugging

401 vs 403

401: “Who are you?” Authentication/token problem.

403: “I know who you are, but no.” Authorization/policy problem.

502 vs 504

502: Proxy/gateway could not get a valid upstream response.

504: Proxy/gateway waited for upstream and timed out.

Debugging rule: 4xx → inspect what the client sent. 5xx → inspect the application, proxy, gateway, and upstream chain.

One subtle one: 404

For APIs, 404 does not always mean “the server is down.” It can mean the wrong route, base path, gateway mapping, nginx location rule, API version, or hostname was used.
