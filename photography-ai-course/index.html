Course promise / 课程目标

See. Decide. Make. Edit. Explain.

Each day isolates one variable so improvement comes from comparison, not equipment purchases or cosmetic filters.

每天只聚焦一个关键变量，让进步来自可比较的实验，而不是器材消费或装饰性滤镜。

How to work / 学习方法

One lesson, one field test, one honest critique.

Shoot the baseline first. Change one thing. Review at full screen. Select on evidence. Write down the next experiment.

先拍基准图；每次只改变一个变量；全屏复盘；依据证据选片；写下下一次实验。

Learning path / 学习路径

Four modules, one visual language.

Days 1–7

Scenes / 场景

Organize light, space, color, motion, and atmosphere inside one frame.

在一张照片中组织光线、空间、色彩、运动与氛围。

Days 8–14

People / 人物

Build trust first, then photograph gesture, expression, and relationship.

先建立信任，再拍摄动作、表情与关系。

Days 15–21

Objects / 物件

Shape meaning through form, surface, context, scale, and arrangement.

通过形状、表面、语境、尺度与排列塑造意义。

Days 22–28

Complete Photo Stories / 完整摄影故事

Turn individual frames into a coherent, ethical sequence.

把单张照片编成连贯、诚实的叙事。

DAY 01 Light reveals the subject光线决定你看见什么 Scenes / 场景

Learning objectives / 学习目标

Explain how directional light and protected highlights changes a photograph's meaning.

说明“方向光与高光保护”如何改变照片意义。

Use a smartphone deliberately to control directional light and protected highlights.

有意识地使用手机控制“方向光与高光保护”。

Annotated example / 示例读图

1

The strongest contrast establishes the first reading of light reveals the subject.

最强反差建立了对“光线决定你看见什么”的第一层阅读。

2

Edge spacing and background details either support or compete with directional light and protected highlights.

边缘间距与背景细节会支持或干扰“方向光与高光保护”。

3

The frame becomes stronger when every visible element has a clear job.

画面中每个可见元素都有明确作用时，照片会更有力量。

Photography theory / 摄影理论

Light creates shape before composition organizes it. Direction, softness, and color decide which surfaces become visible and which recede.

光线先塑造形体，构图再组织形体。光线的方向、软硬与色彩，决定哪些表面被看见、哪些退入背景。

Smartphone-camera technique / 手机相机操作

1

Tap the key subject, then lower exposure slightly when highlights begin to lose detail.

点击关键主体；当高光开始失去细节时，略微降低曝光。

2

Clean the lens, use the main camera when possible, and avoid digital zoom.

擦净镜头，尽量使用主摄，并避免数码变焦。

3

Tap the meaningful subject, lock focus/exposure when needed, and make a second frame slightly darker.

点击关键主体；需要时锁定对焦与曝光，并补拍一张稍暗版本。

Common mistakes / 常见错误

Treating directional light and protected highlights as decoration instead of a decision.

把“方向光与高光保护”当作装饰，而不是决定。

Changing several variables at once, making comparison impossible.

一次改变多个变量，导致无法比较。

Using a filter to hide weak seeing, timing, or framing.

用滤镜掩盖观察、时机或构图不足。

Step-by-step shooting exercise / 分步拍摄练习

1

Choose one ordinary, safe subject and state what the photograph should communicate.

选择一个普通且安全的主体，并说清照片要传达什么。

2

Make a neutral baseline frame before changing anything.

先拍一张中性基准图，再做改变。

3

Create three variations that change only directional light and protected highlights.

只改变“方向光与高光保护”，拍三个版本。

4

Review at full screen; check edges, focus, highlights, and distracting mergers.

全屏查看，检查边缘、焦点、高光和干扰性重叠。

5

Select one frame and write one sentence explaining why it works.

选出一张，并用一句话说明它为何有效。

Editing exercise / 后期练习

1

Straighten and crop only to strengthen the original intention.

只为强化原意而校正与裁剪。

2

Adjust exposure, highlights, shadows, and contrast in small steps while watching natural transitions.

小幅调整曝光、高光、阴影与反差，并留意自然过渡。

3

Correct color cast before adding saturation; compare the edit with the original.

先校正偏色，再考虑饱和度；把成片与原片对照。

Assignment / 作业

Submit three frames of one place in front, side, and back light. Explain which version communicates best.

提交同一地点的顺光、侧光、逆光三张照片，并说明哪一张最有表达力。

Critique rubric / 点评量表

Criterion / 标准4 → 1 evidence / 证据
Intent: the frame clearly demonstrates directional light and protected highlights.意图：画面清楚呈现“方向光与高光保护”。 4 清楚有意；3 基本有效；2 部分控制；1 意图不清。
Technical control: focus, exposure, and color support the subject.技术控制：对焦、曝光与色彩服务主体。 4 清楚有意；3 基本有效；2 部分控制；1 意图不清。
Visual organization: edges, background, and timing feel deliberate.视觉组织：边缘、背景和时机具有明确意图。 4 清楚有意；3 基本有效；2 部分控制；1 意图不清。
Reflection: the photographer can explain one choice and one next experiment.反思：拍摄者能说明一个选择和下一次实验。 4 清楚有意；3 基本有效；2 部分控制；1 意图不清。

Photography theory / 摄影理论

Editing is an argument about what the story contains. Select for meaning first, then technical quality, and remove redundancy even when a frame is beautiful.

编辑是在论证故事包含什么。先按意义选，再看技术质量；即使照片漂亮，重复也要删除。

Smartphone-camera technique / 手机相机操作

1

Use flags or albums consistently; avoid editing inside the full camera roll.

统一使用标记或相册，不要在完整相机胶卷里混乱编辑。

2

Clean the lens, use the main camera when possible, and avoid digital zoom.

擦净镜头，尽量使用主摄，并避免数码变焦。

3

Tap the meaningful subject, lock focus/exposure when needed, and make a second frame slightly darker.

点击关键主体；需要时锁定对焦与曝光，并补拍一张稍暗版本。

Common mistakes / 常见错误

Treating truthful selection and captioning as decoration instead of a decision.

把“真实的选片与说明”当作装饰，而不是决定。

Changing several variables at once, making comparison impossible.

一次改变多个变量，导致无法比较。

Using a filter to hide weak seeing, timing, or framing.

用滤镜掩盖观察、时机或构图不足。

Step-by-step shooting exercise / 分步拍摄练习

1

Choose one ordinary, safe subject and state what the photograph should communicate.

选择一个普通且安全的主体，并说清照片要传达什么。

2

先拍一张中性基准图，再做改变。

3

Create three variations that change only truthful selection and captioning.

只改变“真实的选片与说明”，拍三个版本。

4

Review at full screen; check edges, focus, highlights, and distracting mergers.

全屏查看，检查边缘、焦点、高光和干扰性重叠。

5

Select one frame and write one sentence explaining why it works.

选出一张，并用一句话说明它为何有效。

Editing exercise / 后期练习

1

Straighten and crop only to strengthen the original intention.

只为强化原意而校正与裁剪。

2

Adjust exposure, highlights, shadows, and contrast in small steps while watching natural transitions.

小幅调整曝光、高光、阴影与反差，并留意自然过渡。

3

Correct color cast before adding saturation; compare the edit with the original.

先校正偏色，再考虑饱和度；把成片与原片对照。

把十二张精简为七张，并添加只陈述已核实事实的说明文字。
