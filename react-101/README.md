# React 101 — CT Core-style portal

Two public, fictional examples with identical behavior:
- `vanilla/index.html` — direct DOM manipulation with plain HTML and JavaScript.
- `react/index.html` — browser-ready React using `React.createElement`, `useState` and `useMemo`, importing React from esm.sh.

Open `index.html` for the complete five-lesson comparison. A separately downloadable ZIP contains the real Vite + JSX source project, which can be developed with `npm install`, `npm run dev` and built with `npm run build`. The browser-ready CDN demo hosted here is **not** a Vite production build. It requires access to the public CDN.

All application names and data are fictional and do not expose internal corporate URLs or bank systems.
